# 字行 · 微信竖屏小游戏

以「青翠森林轻量版」为玩法基础，美术现已改为参考图的桌面微缩世界：蓝色裁切垫、点阵纸、横线笔记本与巨型文具；原有三区及圣地依次呈现为胶佬工作台、手帐漫游、文具高塔、字灵书庭。首页、选字、地图、难度、战斗信息、升级、进阶、老虎机、暂停、结算、属性、研究所与设置采用统一纸张与墨线设计。微信运行包由源码生成到 `minigame/`，构建后可直接用微信开发者工具打开本项目，无需启动电脑上的网页服务器。

Git 仓库保留源码、原始素材、构建工具、依赖锁文件及必要配置。`node_modules/`、`minigame/`、本地存档、备份、日志、个人微信配置及验收截图不提交；首次从 GitHub 拉取后，请先按「修改与构建」安装依赖并构建。

## 打开与游玩

1. 微信开发者工具导入 **本项目根目录** `D:\原始竖版字灵游戏`，不要只导入 `minigame`。
2. 使用保留的 AppID `wxa545e5ead35ffb1b`，项目类型为小游戏，点击编译。
3. 点击「开始旅程」，选择火、水或木，再选择胶佬工作台和难度。首次进入自动建立本地游客存档，并下载、解压分包。

手机预览请在 **本目录对应的「字行森林竖屏版」窗口** 点击预览。同一 AppID 还用于其他本地工程，扫码前应核对开发者工具中的项目目录；当前首页应显示「字行」及「开始旅程」。完全退出手机中的小游戏，清理本工程的**编译缓存**，重新预览并扫描新码，无需删除游戏存档。

推荐在本目录运行 `npm run preview`：它会先构建，清理本工程的编译缓存，再指定当前目录生成二维码，保存到 `验收/手机预览/预览二维码.jpg`。首次使用前需要按下文安装 `tools/` 构建依赖；若微信开发者工具安装在其他位置，可通过 `WECHAT_DEVTOOLS_CLI` 指定 `cli.bat` 路径。此命令不清理存档，也不执行正式上传。

固定竖屏与俯视镜头：大招左侧显示常驻的大圆摇杆，拖动控制方向，松手停止并回中；也支持在任意空白处滑动移动，轻触空白处不移动。镜头只跟随角色，不支持拖动旋转、双指缩放或滚轮调镜头；战斗自动瞄准和攻击，右侧紫色按钮释放大招。扩展操作按钮及其设置已移除，旧存档也不会创建跳跃、冲刺、锁定或瞄准切换按钮。移动时可用另一根手指点击大招；从按钮开始的手势不会触发移动。靠近经验、金币及掉落道具即自动吸附，锁定吸附后持续跟随，宝箱等互动仍需点击交互按钮。右上小地图下方的圆形按钮暂停；详情、升级选项和结算内容可上下滑动。界面避开刘海、微信胶囊和底部安全区。

## 修改与构建

首次拉取或需要修改源码时，使用 Node.js 22 或更新版本。首次构建会自动生成资源包，需要 Python 与 `fonttools`；默认 Windows 使用 Python 3.13，也可通过 `POKEBONK_PYTHON` 指定已安装 `fonttools` 的 Python 可执行文件。在本目录执行：

```powershell
npm ci --prefix tools
py -3.13 -m pip install fonttools
npm run build
```

新版字行界面由原生弹性布局计算，修改布局后运行 `npm run build` 即可；`npm run layout` 仅用于旧界面的参考尺寸。测试需要本机 Chrome，可用 `CHROME_PATH` 指定路径；默认使用 `C:/Program Files/Google/Chrome/Application/chrome.exe`。

原始字形保存在 `source/art/glyphs/`。修改字形后先运行 `node tools/glyph-atlas.mjs`，再运行 `npm run build:assets`。其他资源修改后也运行 `npm run build:assets`；该命令同时更新 `source/src/actor-metrics.js` 的碰撞尺寸，请一并提交。首次更新到中文精简版时，也需要运行一次 `build:assets`，避免混用旧资源包。FFmpeg 随构建依赖提供。已有本地 `minigame/` 运行包时，只打开微信开发者工具游玩不需要重新安装构建依赖。

当前资源筛选及音乐分包规则在 `tools/asset-policy.mjs`，道具生成清单由 `source/src/paper-prop-names.js` 与运行时共享。普通 `npm run build` 会检测资源策略版本并自动更新旧包；修改筛选或分包规则时递增 `assetPolicyVersion`。开放其他地图、活动、角色或旧社交界面前，需同步复核排除规则并重新生成资源。资源核验会检查当前地图、活动范围和必要共享素材，防止只改入口却遗漏资源。

```powershell
npm test
npm run verify:assets
$env:POKEBONK_QA = Join-Path (Get-Location) '验收\竖屏'
npm run test:touch
npm run test:menus
npm run test:ui-perf
npm run test:performance
npm run test:loading
npm run test:scenes
```
