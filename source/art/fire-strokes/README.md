# 火系主角动作

炎、焱、燚分别有 8、12、16 张原始笔画 PNG。每个「火」含左点、长撇、右点、右捺。角色动作使用 512 × 512 原画坐标。每个部件有自己的旋转中心，组内的笔画随组一起移动。

## 预览动作

进入开发测试版，用炎开局。在战斗的「测试」面板点「预览偏旁动作」，上方的「火」会倾斜，其中的左点会抬起，再回到原位。在同一面板点「升到下次进化」并确认，可在焱和燚形态重复预览。

## 编写关键帧

在角色动画逻辑中把关键帧赋给玩家的 `firePose`。每次换帧传入新的对象，同一帧可重复使用。下例让炎的上火上移，并让其中的左点单独旋转。

```js
player.firePose = {
  word: '炎',
  groups: { '上火': { y: -8 } },
  strokes: { '上火': { '左点': { angle: 25 } } }
};
```

- 炎的组名为「上火、下火」，焱为「上火、左下火、右下火」，燚为「左上火、右上火、左下火、右下火」。
- `x` 向右，`y` 向下，单位均为原画像素。`angle` 使用顺时针角度。`scaleX` 和 `scaleY` 默认为 1。`px`、`py` 可指定原画上的旋转中心，默认使用部件中心。
- 未指定的部件使用站姿。动作结束时设 `player.firePose = null`。建议把大幅伸展的动作放进游戏检查边缘留白。
- 替换原画时保留画布和笔画编号。从工程根目录运行 `node tools/fire-strokes.mjs` 生成图集与定位表，再运行 `node tools/build.mjs --assets`。开发测试包使用 `node tools/build.mjs --dev --assets`。
